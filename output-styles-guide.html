═══ What Are Output Styles? ═══

Output styles in Claude Code allow you to customize how Claude formats its responses. Instead of plain text, Claude can format responses as HTML pages, YAML structures, or any custom format you define.

📍 Location: .claude/output-styles/*.md
🔧 Activation: Use /output-style command
📚 Documentation: Official Docs

═══ How to Use Output Styles ═══

▸ Activating a Style

claude
/output-style

This opens an interactive menu where you can select from available styles.

▸ Creating Custom Styles

  1. Create a new .md file in .claude/output-styles/
  2. Add YAML frontmatter with name and description
  3. Write formatting instructions in the body
  4. Restart Claude Code or use /output-style to refresh

▸ File Structure

.claude/
└── output-styles/
    ├── retro-ascii-blog.md
    ├── yaml-concise.md
    └── your-custom-style.md

▸ Example Custom Style Template

---
name: My Custom Style
description: Brief description of what this style does
---

Format all responses following these rules:
- Rule 1
- Rule 2
- Rule 3
