🏗️ System Architecture

Component Hierarchy

Server Component Strategy: Next.js App Router uses Server Components by default for optimal performance and SEO. Client Components (marked with "use client") are used only for interactive UI elements that require state management.

📂 Hook Categories

HookHub organizes hooks into 13 distinct categories based on Claude Code's lifecycle events and hook types.
Category Type Description Examples
PreToolUse Lifecycle Executes before tool usage activity-logger, prompt-validator
PostToolUse Lifecycle Executes after tool usage format-typescript, auto-git-stage
SessionStart Lifecycle Runs when session begins session-logger, env-checker
SessionEnd Lifecycle Runs when session ends cleanup-temp-files, session-summary
UserPromptSubmit Context Triggered on user input context-enhancer, auto-context-loader
PermissionRequest Context Handles permission prompts auto-approver, security-check
SubagentStop Context Subagent completion handler result-summarizer, notification-sender
PreCompact Context Before context compression context-saver, memory-manager
Stop Lifecycle Cleanup before shutdown state-saver, backup-creator
Notification User-Facing Custom notifications sound-notifier, desktop-alert
Utility Meta General utilities code-formatter, linter
Workflow Meta Multi-step workflows commit-and-push, test-and-deploy
Other Meta Uncategorized hooks Experimental or misc
